Response after changes requested

For each CHANGES_REQUESTED review, how long until someone reacts — via comment, body edit, or terminating the PR. Because many PRs are opened by github-actions[bot] on behalf of a human submitter, we don't require the responder to be the recorded PR author: we take the first non-bot user other than the reviewer to act on the PR. Each CR review is a separate cycle (one PR can have several rounds). Anchored on the CR date with a ±1-day sliding window (adjustable) and d3.curveBasis smoothing across neighbouring days.
